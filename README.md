# Port Viewer

面向 Windows 开发者的中文端口管理桌面工具。用于查看本机 TCP/UDP 端点、定位占用进程并在确认后释放端口。

## 功能

- 使用 Windows 原生 `netstat` 与 `tasklist` 并行快速扫描 TCP 监听端口和 UDP 端点
- 按端口、PID、进程名、路径搜索
- 自动识别 Web 与后端、数据存储、消息中间件、基础设施、AI 与模型服务
- 用中文解释常见端口和进程的用途，并提示监听范围
- 按需显示厂商、产品、文件描述、数字签名、运行账户、父进程、资源占用和关联 Windows 服务
- 显示进程路径、完整命令行、启动时间及同一进程占用的其他端口
- 列表页和详情页都可结束进程，操作前二次确认并内置 Windows 关键进程保护
- 双击进程所在行，在资源管理器中定位可执行文件
- 手动刷新为默认模式，可按需开启自动刷新
- 默认亮色主题，可切换并记住深色主题偏好
- 无边框窗口

## 本地运行

```powershell
npm install
npm start
```

## 打包 Windows 程序

```powershell
npm run build
```

生成结果位于 `dist`。结束高权限进程时，需要以管理员身份运行 Port Viewer。

## 安全说明

结束进程前会展示进程名称、PID 和可执行文件路径，并要求再次确认。工具会拒绝结束 PID 4 及常见 Windows 关键进程，但仍应在操作前确认目标进程，避免未保存的数据丢失。
